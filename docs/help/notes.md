# Working with notes

Each note is its own small window. Everything you can do to a note lives in its **header bar**
and its **right-click menu**.

## The header bar

Buttons run left-to-right across the top of the note:

| Button | What it does | Shortcut |
|---|---|---|
| **Favourite** | Marks the note as a favourite (star). Favourites sort/tag-pin in the list | `Ctrl+F` |
| **Colour** | Opens the colour picker (8 colours) | — |
| **Pin** | Always-on-top on/off. The icon changes to show which state it is in | `Ctrl+P` |
| **Collapse** | Shrinks the note to just its header, and back | `Ctrl+M` |
| **Lock** | Locks the note so it cannot be edited by accident | `Ctrl+L` |
| **Checklist** | Switches between plain text and a checklist | `Ctrl+K` |
| **Close** | Closes the note window (the note is kept) | `Ctrl+Esc` |

Drag the header bar to move the note; drag any edge or corner to resize it.

> The toolbar can auto-hide — see **Settings → Appearance → Auto-hide Toolbar**.

## Colours

Eight colours are available from the colour button: **Yellow, Green, Blue, Pink, Purple,
Orange, White, Gray**. The colour also determines how notes group in the Notes List.

## Always on top (pin)

Pinning keeps a note above your other windows while you work elsewhere.

- Click the **pin** button (`Ctrl+P`). The pin icon changes to show it is active.
- Pinned notes stay on top even when you switch to another application, and the setting is
  remembered across restarts.
- Unpin to let the note behave like a normal window again.

> A note cannot stay above another window that is *itself* always-on-top (Task Manager, some
> media players and launch tools, or a full-screen game). That is a Windows rule: always-on-top
> windows are ordered among themselves.

> Note windows are deliberately **not** listed in Alt-Tab or the taskbar — they behave like
> desktop widgets. Use the Notes List (`Ctrl+Alt+F`) to find a note.

## Lock and collapse

- **Lock** (`Ctrl+L`) — prevents accidental edits. While locked, the paint/edit actions are
  disabled (the pin, colour, collapse and checklist buttons are greyed out). `Ctrl+D` (delete)
  is also disabled while locked.
- **Collapse** (`Ctrl+M`) — keeps only the header visible, handy for a note you want out of the
  way but still on screen. The collapsed state is remembered.

## Text size

Hold **Ctrl** and scroll the mouse wheel over the note to change its font size. The size is
saved with the note.

## Checklist

Pressing `Ctrl+K` (or the checklist button) turns the note's body into a checklist. Each item
can be ticked off, and the Notes List shows such notes as `Checklist` so you can spot them.

## Tags

The strip along the bottom of a note holds its tags. Tags are searchable and can be used to
filter in the Notes List.

## Right-click menu

Right-click anywhere on a note:

| Item | What it does |
|---|---|
| **New Note** | Creates another note |
| **Duplicate** | Copies the current note |
| **Always on Top** | Same as the pin button |
| **Lock** | Same as the lock button |
| **Collapse** | Same as the collapse button |
| **Delete** | Deletes the note (asks first, if *Confirm before deleting notes* is on) |
| **Properties** | Shows details about the note |

## Deleting a note

`Ctrl+D`, or right-click → **Delete**. If **Settings → General → Confirm before deleting notes**
is enabled (the default), you are asked to confirm. Deleted notes are gone — recover them from a
[backup](backup-and-restore.md) if needed.
