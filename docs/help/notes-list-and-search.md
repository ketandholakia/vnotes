# Notes List & search

The Notes List is where you find, filter and open notes. Open it from the tray icon
(**Open Notes List**), with `Ctrl+Alt+F`, or by left-clicking the tray icon.

## What it shows

Notes are listed in a tree, grouped **by colour**. Each group row looks like:

```
📁 Yellow - 3 Notes
```

and each note row has these columns:

| Column | Contents |
|---|---|
| Marker | 📌 — this is a note row |
| Title | The note's title, or *(untitled)* |
| Updated | The date the note was last changed |
| Type | `✅ Checklist` or `📝 Memo` |
| Tags | The note's tags, e.g. `[work, urgent]` |
| Colour | The note's colour swatch |

## Searching

Type in the search box at the top. The list filters as you type — the search covers note
titles, note content, tags and checklist items. Pressing `Ctrl+Alt+F` opens the list with the
search box already focused, so you can start typing immediately.

## Filtering by tag

The dropdown next to the search box lists every tag in use. Choose one to show only notes
carrying that tag; choose **All Tags** to clear the filter.

## Opening notes

Select a row and click **Open** (or use the note's group to locate it). The note window is
brought to the front.

## Arranging note windows

From the tray menu, **Arrange Notes ▸** lays out the note windows that are currently open:

| Option | Layout |
|---|---|
| **Cascade** | Stacked diagonally, each offset from the last |
| **Grid** | Evenly spread across the work area |
| **By Color** | Grouped so notes of the same colour sit together |
| **By Tag** | Grouped so notes sharing a tag sit together |

## Multi-monitor

Note positions are saved per note. If a monitor is unplugged, notes that would land off-screen
are pulled back into the visible work area on the next start, and the corrected position is
saved.
