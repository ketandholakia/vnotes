# Keyboard shortcuts

## Global — work anywhere in Windows

These use Windows global hotkeys, so they work even when V-Notes is not the active window.
They can be changed in **Settings → Hotkeys**.

| Shortcut | Action |
|---|---|
| `Ctrl+Alt+N` | Create a new note |
| `Ctrl+Alt+F` | Open the Notes List with the search box focused |

The tray menu shows the shortcuts you have configured.

> If a global hotkey does not respond, another application may already own that combination.
> V-Notes will report the clash; see [Troubleshooting](troubleshooting.md#global-hotkeys-do-not-work).

## Note window — while a note has focus

| Shortcut | Action |
|---|---|
| `Ctrl+F` | Toggle favourite |
| `Ctrl+P` | Toggle always-on-top (pin) |
| `Ctrl+M` | Toggle collapse |
| `Ctrl+L` | Toggle lock |
| `Ctrl+K` | Toggle checklist |
| `Ctrl+D` | Delete note (disabled while the note is locked) |
| `Ctrl+Esc` | Close the note window |
| `Alt+F4` | Close the note window |
| `Ctrl` + mouse wheel | Change the note's font size |

## Notes List

| Input | Action |
|---|---|
| Typing in the search box | Filters notes as you type |
| Tag dropdown | Restricts the list to one tag (*All Tags* shows everything) |
| **Open** | Opens the selected note |

## Text editing

Inside the note body the usual Windows editing keys apply (`Ctrl+A`, `Ctrl+C/X/V`, `Ctrl+Z`,
`Ctrl+Backspace`, etc.).
